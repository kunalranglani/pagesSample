## Welcome to GitHub Pages

### Equivalent fractions practice

Open [Equivalent Fractions](equivalent-fractions.html) from the home page for a
fourth-grade worksheet with equal-sized fraction bars and 20 randomized questions.
Practice missing numerators, missing denominators, and recognizing equivalent
fractions using denominators up to 12. Use **Check My Answers** for feedback,
**Show Answer Key** for worked explanations, or **New Questions** for a fresh set.
**Print Worksheet** prints the current questions; keep the answer key hidden for
a student worksheet, or show it to include it on a separate page.

### Multiplication tables

Use [Multiplication Tables 1-10](multiplication-tables-1-10.html) or
[Multiplication Tables 11-20](multiplication-tables-11-20.html) from the home page.
Each question-only worksheet includes all ten tables in its range, with each
number multiplied by 1 through 10 (100 questions per page). Answers are blank,
with no solutions or answer key. Fill in the boxes on screen or use your
browser's Print command for a paper worksheet.
